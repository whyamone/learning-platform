# Практика

Сделай агента с инструментами: разбор конфигурации устройства, поиск в журнале событий, расчёты по адресации, поиск по базе знаний через RAG. Сценарии: «найди причину падения порта», «проверь конфигурацию на типичные ошибки», «объясни, что изменилось между двумя версиями». Используй только выдуманные конфигурации.
