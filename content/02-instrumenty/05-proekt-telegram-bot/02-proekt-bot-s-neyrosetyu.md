# Практика

Напиши бота, который пересылает сообщения локальной модели в Ollama и возвращает ответ. Требования: история диалога в базе, команда сброса контекста, системный промпт с ролью «помощник сетевого инженера», ограничение длины истории, понятные сообщения об ошибках, запуск через `docker compose`, README и тесты.
