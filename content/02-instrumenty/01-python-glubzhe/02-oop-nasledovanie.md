# Практика

От базового класса `Device` унаследуй `Switch` и `Router`. У каждого свой метод `describe()`. Напиши функцию, которая принимает список любых устройств и вызывает `describe()` у каждого. Затем вынеси интерфейс в отдельный класс `Interface` и подключи его через композицию.
