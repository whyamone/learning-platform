# Практика

Опиши класс `Device` с атрибутами `hostname`, `ip`, `vendor` и списком интерфейсов. Добавь методы `add_interface()`, `active_interfaces()` и `__str__()`. Создай несколько устройств и выведи сводку по каждому.
