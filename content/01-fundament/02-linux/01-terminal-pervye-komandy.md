# Теория

## Зачем нужен терминал

Терминал — это окно, в котором ты управляешь компьютером текстовыми командами.
На серверах графического интерфейса обычно нет вообще: только терминал.
Поэтому для разработчика это основной рабочий инструмент.

Внутри терминала работает **командная оболочка** (shell) — программа, которая
принимает твои команды и запускает их. В Ubuntu это `bash`.

## Строка приглашения

Когда терминал готов принять команду, он показывает приглашение:

```text
ivan@laptop:~$
```

Что здесь написано:

- `ivan` — имя пользователя;
- `laptop` — имя компьютера;
- `~` — текущая папка (значок `~` означает домашнюю папку);
- `$` — признак обычного пользователя (у администратора вместо него `#`).

Приглашение печатает сама оболочка. Набирать его не нужно — только команду после него.

## Из чего состоит команда

```bash
ls -l /home
```

- `ls` — сама команда (что сделать);
- `-l` — опция (как именно сделать), начинается с дефиса;
- `/home` — аргумент (с чем сделать).

Части разделяются пробелами. Регистр важен: `ls` и `LS` — разные слова.

## Где я? Команда pwd

```bash
pwd
```

```text
/home/ivan
```

Команда показывает **текущую папку** — ту, в которой ты сейчас «стоишь».
Большинство команд работает именно с ней.

## Что здесь лежит? Команда ls

```bash
ls
```

Полезные опции:

| Команда | Что показывает |
|---|---|
| `ls` | Имена файлов и папок |
| `ls -l` | Подробный список: права, владелец, размер, дата |
| `ls -a` | Все файлы, включая скрытые (их имена начинаются с точки) |
| `ls -la` | Опции можно объединять: подробно и со скрытыми |
| `ls /etc` | Содержимое другой папки, не переходя в неё |

## Перемещение. Команда cd

```bash
cd /etc        # перейти в папку /etc
cd ~           # вернуться в домашнюю папку
cd ..          # подняться на уровень выше
cd -           # вернуться в предыдущую папку
```

Две точки `..` означают «папка уровнем выше», одна точка `.` — «текущая папка».

## Абсолютные и относительные пути

Файловая система Linux — это дерево. Его корень обозначается одним слэшем `/`.

```text
/
├── etc
├── home
│   └── ivan
│       └── study
│           └── notes.txt
└── var
```

К файлу `notes.txt` можно прийти двумя способами:

- **Абсолютный путь** начинается с `/` и описывает дорогу от корня:
  `/home/ivan/study/notes.txt`. Работает из любого места.
- **Относительный путь** описывает дорогу от текущей папки. Если ты стоишь
  в `/home/ivan`, то путь будет `study/notes.txt`.

Как сетевому инженеру тебе поможет сравнение: абсолютный путь — как полный
адрес с индексом, относительный — как «второй дом налево отсюда».

## Создание папок и файлов

```bash
mkdir projects                 # создать папку
mkdir -p study/linux/day1      # создать сразу всю цепочку вложенных папок
touch notes.txt                # создать пустой файл
cat notes.txt                  # показать содержимое файла
```

Записать строку в файл можно так:

```bash
echo "Первая заметка" > notes.txt
```

Команда `echo` печатает текст, а знак `>` перенаправляет его в файл вместо экрана.
Осторожно: `>` стирает прежнее содержимое файла. Чтобы дописать в конец, используй `>>`.

## Приёмы, которые экономят время

- **Tab** — автодополнение. Набери `cd pro` и нажми Tab: оболочка допишет `projects/`.
  Если вариантов несколько, нажми Tab дважды — увидишь список.
- **Стрелки вверх и вниз** — листать историю команд.
- **Ctrl+C** — прервать команду, которая выполняется.
- **Ctrl+L** — очистить экран.

## Как узнать, что делает команда

```bash
ls --help      # краткая справка
man ls         # подробное руководство (выход — клавиша q)
```

Справка написана по-английски. Не обязательно читать всё: ищи нужную опцию
и её короткое описание.

```text
study/
├── linux/
│   └── notes.txt
└── python/
```

В файл `notes.txt` запиши строку с сегодняшней датой, потом допиши вторую строку
с названием этой темы. Проверь результат командой `cat`.

**Задание 3.** Находясь в папке `study/linux`, перейди в `study/python` двумя
способами: по абсолютному пути и по относительному.

**Задание 4.** С помощью `ls -la` найди в домашней папке скрытые файлы.
Выпиши названия трёх из них в `notes.txt`.
