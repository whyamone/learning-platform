# Теория

## cat — вывести файл целиком

```bash
cat /etc/hostname
cat -n notes.txt              # с номерами строк
cat part1.txt part2.txt       # несколько файлов подряд
```

Подходит для коротких файлов. Файл на тысячу строк пролетит по экрану,
и ты увидишь только конец.

## less — постраничный просмотр

```bash
less /var/log/dpkg.log
```

Файл открывается на весь экран, и по нему можно перемещаться.

| Клавиша | Действие |
|---|---|
| стрелки, `PgUp`, `PgDn` | перемещение |
| `Пробел` | на экран вниз |
| `g` / `G` | в начало / в конец |
| `/текст` | поиск вперёд |
| `n` / `N` | следующее / предыдущее совпадение |
| `q` | выйти |

`less` не загружает файл в память целиком, поэтому мгновенно открывает
даже логи на несколько гигабайт. Те же клавиши работают в `man`.

## head и tail — начало и конец

```bash
head notes.txt                # первые 10 строк
head -n 3 notes.txt           # первые 3 строки
tail notes.txt                # последние 10 строк
tail -n 20 /var/log/dpkg.log  # последние 20 строк
```

В логах самое свежее — в конце. Поэтому `tail` используется постоянно.

## tail -f — следить за файлом

```bash
tail -f /var/log/dpkg.log
```

Команда выводит последние строки и остаётся работать: каждая новая запись
в файле сразу появляется на экране. Так наблюдают за работающей программой.
Выход — `Ctrl+C`.

Это аналог `terminal monitor` на сетевом оборудовании.

## Редактор nano

Простой редактор, подсказки по клавишам видны внизу экрана.

```bash
nano notes.txt
```

Знак `^` в подсказках означает клавишу `Ctrl`.

| Клавиши | Действие |
|---|---|
| `Ctrl+O`, затем `Enter` | сохранить |
| `Ctrl+X` | выйти |
| `Ctrl+W` | поиск |
| `Ctrl+K` | вырезать строку |
| `Ctrl+U` | вставить вырезанное |
| `Alt+U` | отменить действие |

Если указать имя несуществующего файла, `nano` создаст его при сохранении.

## Минимум по vim

На серверах `nano` есть не всегда, а `vim` (или его предшественник `vi`)
есть практически везде. Поэтому нужно уметь хотя бы открыть файл,
внести правку и выйти.

Главная особенность: у `vim` несколько режимов. Сразу после запуска
ты находишься в **командном** режиме — клавиши не печатают текст, а выполняют команды.

```bash
vim notes.txt
```

Минимальный набор:

1. Нажми `i` — включится режим вставки, внизу появится `-- INSERT --`.
   Теперь можно печатать.
2. Нажми `Esc` — вернёшься в командный режим.
3. Набери `:wq` и `Enter` — сохранить и выйти.

| Команда | Действие |
|---|---|
| `i` | перейти в режим вставки |
| `Esc` | вернуться в командный режим |
| `:w` | сохранить |
| `:q` | выйти |
| `:wq` | сохранить и выйти |
| `:q!` | выйти без сохранения |
| `/текст` | поиск |
| `dd` | удалить строку |
| `u` | отменить |

> Если что-то пошло не так и непонятно, что происходит: нажми `Esc` несколько
> раз, затем набери `:q!` и `Enter`. Это выход без сохранения из любой ситуации.

Глубоко изучать `vim` сейчас не нужно. Для повседневной работы
у тебя будет VS Code.

## Что чем открывать

| Задача | Команда |
|---|---|
| Посмотреть короткий файл | `cat` |
| Изучить длинный файл | `less` |
| Увидеть последние записи лога | `tail -n 50` |
| Следить за логом вживую | `tail -f` |
| Поправить настройку | `nano` |
| Поправить настройку там, где нет nano | `vim` |

# Практика

**Задание 1.** Посмотри файл `/etc/passwd` тремя способами: `cat`, `less`
и `head -n 5`. Через `less` найди в нём строку со своим именем пользователя.

**Задание 2.** Выведи строки с 11-й по 20-ю из любого длинного файла
в `/var/log`, не открывая редактор. Подсказка: `head` и `tail` можно
применить последовательно.

**Задание 3.** Открой два окна терминала. В первом запусти `tail -f ~/test.log`.
Во втором несколько раз выполни `echo "событие" >> ~/test.log`.
Убедись, что строки появляются в первом окне.

**Задание 4.** В `nano` создай файл `~/study/linux/commands.md` и запиши
в него все команды, которые ты уже знаешь, с коротким описанием каждой.
Продолжай пополнять этот файл в следующих темах — получится личная шпаргалка.

**Задание 5.** Открой `commands.md` в `vim`. Добавь строку в конец файла,
сохрани и выйди. Затем открой снова, удали эту строку командой `dd`
и выйди без сохранения. Проверь, что строка осталась на месте.

**Задание 6 (со звёздочкой).** Выполни команду `vimtutor` — это встроенный
интерактивный учебник. Пройди первые два урока.
