# Теория

## Философия маленьких команд

В Linux принято, что каждая команда делает одно дело, но делает его хорошо.
Сложные задачи решаются соединением простых команд в цепочку.

Команда `grep` умеет только искать строки. `sort` — только сортировать.
`wc` — только считать. Вместе они заменяют целую программу анализа логов.

## Три потока

У каждой запущенной программы есть три канала связи:

| Поток | Номер | Назначение | По умолчанию |
|---|---|---|---|
| stdin | 0 | ввод данных | клавиатура |
| stdout | 1 | обычный вывод | экран |
| stderr | 2 | сообщения об ошибках | экран |

Ошибки идут отдельным потоком, чтобы их можно было отделить от полезного вывода.

## Перенаправление вывода в файл

```bash
ls -l > files.txt            # записать вывод в файл (старое содержимое стирается)
date >> files.txt            # дописать в конец файла
ls /nonexistent 2> errors.txt    # в файл попадут только ошибки
ls /etc /nonexistent > out.txt 2> err.txt   # вывод и ошибки — в разные файлы
ls /etc /nonexistent > all.txt 2>&1         # всё в один файл
```

Запись `2>&1` означает «направить поток 2 туда же, куда идёт поток 1».

Особый файл `/dev/null` — «чёрная дыра»: всё записанное туда исчезает.
Так прячут ненужный вывод:

```bash
ping -c 1 192.168.1.1 > /dev/null 2>&1
```

## Конвейер

Символ `|` передаёт вывод одной команды на вход следующей.

```bash
ls /etc | wc -l              # сколько объектов в /etc
ls -l /etc | less            # листать длинный вывод
history | tail -n 5          # последние пять команд
```

Данные идут слева направо, как вода по трубе. Каждая команда получает текст,
что-то с ним делает и передаёт дальше.

## Подготовим данные

Создай файл для опытов — он понадобится во всех примерах ниже.

```bash
cat > ~/access.log << 'EOF'
192.168.1.10 GET /index.html 200
192.168.1.15 GET /login 200
192.168.1.10 POST /login 401
10.0.0.5 GET /admin 403
192.168.1.10 POST /login 200
10.0.0.5 GET /admin 403
192.168.1.22 GET /index.html 200
10.0.0.5 GET /config 403
192.168.1.15 GET /missing 404
192.168.1.10 GET /index.html 200
EOF
```

Конструкция `<< 'EOF'` передаёт команде все строки до слова `EOF`.

## grep — поиск строк

```bash
grep 403 ~/access.log              # строки, где встречается 403
grep -i "get" ~/access.log         # без учёта регистра
grep -v 200 ~/access.log           # строки, где НЕТ 200
grep -n admin ~/access.log         # с номерами строк
grep -c 403 ~/access.log           # только количество совпадений
grep -r "PermitRootLogin" /etc/ssh # поиск во всех файлах папки
grep -E "401|403" ~/access.log     # 401 или 403
```

Опорные символы: `^` — начало строки, `$` — конец.

```bash
grep "^10\." ~/access.log          # строки, начинающиеся с «10.»
grep "200$" ~/access.log           # строки, заканчивающиеся на 200
```

Точка в образце означает «любой символ», поэтому настоящую точку
экранируют обратной косой чертой: `\.`.

Сетевому инженеру `grep` знаком по фильтру `| include` на оборудовании Cisco.
`grep -v` соответствует `| exclude`.

## cut — вырезать колонки

```bash
cut -d " " -f 1 ~/access.log       # первая колонка: IP-адреса
cut -d " " -f 1,4 ~/access.log     # первая и четвёртая
cut -d ":" -f 1 /etc/passwd        # имена пользователей
```

`-d` задаёт разделитель, `-f` — номера полей.

## sort и uniq — сортировка и повторы

```bash
sort names.txt                     # по алфавиту
sort -n numbers.txt                # как числа, а не как текст
sort -r names.txt                  # в обратном порядке
sort -u names.txt                  # отсортировать и убрать повторы
```

`uniq` убирает **соседние** одинаковые строки, поэтому перед ним всегда
ставят `sort`:

```bash
cut -d " " -f 1 ~/access.log | sort | uniq       # уникальные адреса
cut -d " " -f 1 ~/access.log | sort | uniq -c    # с количеством повторений
```

## wc — подсчёт

```bash
wc -l ~/access.log                 # количество строк
grep 403 ~/access.log | wc -l      # сколько запросов получили отказ
```

## Собираем конвейер: топ адресов

Задача: какие адреса обращались чаще всего?

```bash
cut -d " " -f 1 ~/access.log | sort | uniq -c | sort -rn | head -n 3
```

```text
      4 192.168.1.10
      3 10.0.0.5
      2 192.168.1.15
```

Разбор по шагам:

1. `cut -d " " -f 1` — оставить только адреса;
2. `sort` — собрать одинаковые рядом;
3. `uniq -c` — схлопнуть повторы и посчитать их;
4. `sort -rn` — отсортировать по числу, от большего к меньшему;
5. `head -n 3` — взять первые три.

Связка `sort | uniq -c | sort -rn | head` — готовый рецепт на всю жизнь.
Строй конвейеры постепенно: добавил команду, посмотрел результат, добавил следующую.

## Другие полезные команды

```bash
ls | tee files.txt                 # и на экран, и в файл одновременно
cat ~/access.log | tr 'a-z' 'A-Z'  # заменить строчные буквы на заглавные
awk '{print $1, $4}' ~/access.log  # вывести первую и четвёртую колонки
```

`awk` — мощный инструмент обработки колонок. Пока достаточно знать приём
`awk '{print $N}'`: он удобнее `cut`, когда между колонками несколько пробелов.

**Задание 6.** Выведи адреса, которые получили хотя бы один ответ 403,
