# Теория

## Что такое скрипт

Скрипт — текстовый файл с командами, которые ты мог бы набрать вручную.
Оболочка выполняет их по порядку.

```bash
#!/usr/bin/env bash
# Мой первый скрипт

echo "Сегодня: $(date +%F)"
echo "Пользователь: $USER"
echo "Папка: $PWD"
```

Первая строка называется **shebang**. Она сообщает системе, какой программой
выполнять файл. `#!/usr/bin/env bash` означает «найди bash и запусти им».

Сохрани как `info.sh`, сделай исполняемым и запусти:

```bash
chmod +x info.sh
./info.sh
```

## Bash или Python

| Задача | Что выбрать |
|---|---|
| Запустить несколько команд подряд | Bash |
| Обернуть вызовы других программ | Bash |
| Разобрать текст, посчитать, сравнить | Python |
| Больше тридцати-сорока строк логики | Python |

Bash хорош как «клей» между программами. Сложную логику на нём писать
трудно и ненадёжно — для этого у тебя есть Python.

## Переменные

```bash
name="sw-core-1"
count=24

echo "Устройство $name, портов: $count"
echo "Файл: ${name}.cfg"          # фигурные скобки отделяют имя от текста
```

Пробелов вокруг `=` быть не должно.

**Всегда бери переменные в двойные кавычки**: `"$name"`. Без кавычек значение
с пробелами распадётся на несколько слов, и команда получит не то.

```bash
file="мой отчёт.txt"
rm $file          # попытается удалить два файла: «мой» и «отчёт.txt»
rm "$file"        # удалит один файл с пробелом в имени
```

Разница между кавычками: в двойных переменные подставляются,
в одинарных текст остаётся буквальным.

```bash
echo "Домашняя папка: $HOME"      # Домашняя папка: /home/ivan
echo 'Домашняя папка: $HOME'      # Домашняя папка: $HOME
```

## Подстановка команд

Запись `$(команда)` выполняет команду и подставляет её вывод.

```bash
today=$(date +%F)                 # 2026-01-15
files=$(ls | wc -l)

echo "Сегодня $today, файлов в папке: $files"
```

## Аргументы скрипта

Значения, указанные после имени скрипта, доступны через специальные переменные.

| Переменная | Значение |
|---|---|
| `$1`, `$2`, … | первый, второй аргумент |
| `$0` | имя самого скрипта |
| `$#` | количество аргументов |
| `$@` | все аргументы |

```bash
#!/usr/bin/env bash
echo "Скрипт: $0"
echo "Первый аргумент: $1"
echo "Всего аргументов: $#"
```

```bash
./args.sh sw-1 192.168.1.1
```

## Код возврата

Каждая команда завершается с числовым кодом. **Ноль означает успех**,
любое другое число — ошибку. Код последней команды хранится в `$?`.

```bash
ls /etc > /dev/null
echo $?               # 0

ls /нет-такой-папки 2> /dev/null
echo $?               # 2
```

На этом построены условия: `if` проверяет не «истину», а код возврата команды.

Связки команд:

```bash
mkdir backup && cp *.cfg backup/     # вторая выполнится, только если первая успешна
ping -c 1 10.0.0.1 || echo "Нет связи"   # вторая выполнится, только если первая упала
```

Свой код возврата скрипт задаёт командой `exit`: `exit 0` — успех, `exit 1` — ошибка.

## Условия

```bash
#!/usr/bin/env bash

if [[ $# -lt 1 ]]; then
    echo "Использование: $0 <адрес>"
    exit 1
fi

host="$1"

if ping -c 1 -W 2 "$host" > /dev/null 2>&1; then
    echo "$host доступен"
else
    echo "$host не отвечает"
fi
```

Пробелы внутри `[[ ]]` обязательны. Блок закрывается словом `fi`.

Основные проверки:

| Проверка | Истинна, когда |
|---|---|
| `[[ -f "$path" ]]` | существует файл |
| `[[ -d "$path" ]]` | существует каталог |
| `[[ -z "$var" ]]` | строка пустая |
| `[[ -n "$var" ]]` | строка не пустая |
| `[[ "$a" == "$b" ]]` | строки равны |
| `[[ "$a" != "$b" ]]` | строки различаются |
| `[[ $x -eq $y ]]` | числа равны |
| `[[ $x -lt $y ]]`, `-gt` | меньше, больше |
| `[[ $x -le $y ]]`, `-ge` | меньше или равно, больше или равно |

Для чисел используются буквенные операторы: `-eq`, `-ne`, `-lt`, `-gt`.

## Циклы

Перебор списка значений:

```bash
for host in 192.168.1.1 192.168.1.2 192.168.1.3; do
    echo "Проверяю $host"
done
```

Перебор файлов по шаблону:

```bash
for file in *.cfg; do
    echo "Обрабатываю $file"
    cp "$file" "backup/${file}.bak"
done
```

Перебор чисел:

```bash
for i in {1..5}; do
    echo "Порт $i"
done
```

Чтение файла построчно:

```bash
while read -r line; do
    echo "Строка: $line"
done < hosts.txt
```

## Функции

```bash
log() {
    echo "[$(date +%T)] $1"
}

log "Начинаю резервное копирование"
```

Аргументы функции доступны внутри неё через те же `$1`, `$2`.

## Безопасный режим

Добавляй в начало каждого скрипта строку:

```bash
set -euo pipefail
```

| Опция | Что делает |
|---|---|
| `-e` | остановить скрипт при первой же ошибке |
| `-u` | считать ошибкой обращение к несуществующей переменной |
| `-o pipefail` | считать конвейер неуспешным, если упала любая его часть |

Без неё скрипт после ошибки продолжит выполняться. Классический пример беды:
`cd` в папку не удался, а следующая команда `rm -rf *` сработала в другом месте.

## Пример: резервное копирование

```bash
#!/usr/bin/env bash
# Создаёт архив папки с датой в имени и удаляет архивы старше 7 дней.
set -euo pipefail

source_dir="${1:-$HOME/study}"        # первый аргумент или значение по умолчанию
backup_dir="$HOME/backups"
archive="$backup_dir/study-$(date +%F).tar.gz"

if [[ ! -d "$source_dir" ]]; then
    echo "Папка не найдена: $source_dir" >&2
    exit 1
fi

mkdir -p "$backup_dir"
tar -czf "$archive" -C "$(dirname "$source_dir")" "$(basename "$source_dir")"
echo "Создан архив: $archive ($(du -h "$archive" | cut -f 1))"

find "$backup_dir" -name "study-*.tar.gz" -mtime +7 -delete
```

Запись `${1:-значение}` подставляет значение по умолчанию, если аргумент
не передан. Запись `>&2` направляет сообщение в поток ошибок.

## Запуск по расписанию: cron

`cron` выполняет команды в заданное время. Расписание редактируется так:

```bash
crontab -e
```

Строка расписания состоит из пяти полей времени и команды:

```text
┌──────── минута (0–59)
│ ┌────── час (0–23)
│ │ ┌──── день месяца (1–31)
│ │ │ ┌── месяц (1–12)
│ │ │ │ ┌ день недели (0–7, воскресенье — 0 или 7)
│ │ │ │ │
0 3 * * *  /home/ivan/bin/backup.sh >> /home/ivan/backup.log 2>&1
```

Звёздочка означает «любое значение». Строка выше — каждый день в 03:00.

| Расписание | Когда |
|---|---|
| `*/5 * * * *` | каждые пять минут |
| `0 * * * *` | в начале каждого часа |
| `30 8 * * 1-5` | в 08:30 по будням |
| `0 0 1 * *` | первого числа каждого месяца в полночь |

В расписании указывай полные пути: `cron` запускает команды с минимальным
окружением и не знает о твоей текущей папке. Посмотреть расписание — `crontab -l`.

## Проверка скриптов

Программа `shellcheck` находит типичные ошибки: забытые кавычки,
опечатки в переменных, опасные конструкции.

```bash
sudo apt install -y shellcheck
shellcheck backup.sh
```
