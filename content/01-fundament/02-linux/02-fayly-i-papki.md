# Теория

## Копирование: cp

```bash
cp notes.txt backup.txt            # копия файла под новым именем
cp notes.txt ~/study/              # копия в другую папку с тем же именем
cp -r linux/ linux-backup/         # копия папки со всем содержимым
```

Для папок обязательна опция `-r` (recursive — «вместе с вложенным»).
Без неё `cp` откажется копировать каталог.

Полезные опции: `-i` спрашивает перед перезаписью, `-v` показывает, что копируется.

## Перемещение и переименование: mv

Отдельной команды «переименовать» в Linux нет. Переименование — это
перемещение под другим именем.

```bash
mv old.txt new.txt                 # переименовать
mv notes.txt ~/study/linux/        # переместить в другую папку
mv notes.txt ~/study/linux/day1.txt   # переместить и переименовать сразу
mv linux/ unix/                    # папки переименовываются так же, без -r
```

> `cp` и `mv` перезаписывают существующий файл без предупреждения.
> Добавляй `-i`, если не уверен, что имя свободно.

## Удаление: rm

```bash
rm notes.txt                       # удалить файл
rm -r old-project/                 # удалить папку со всем содержимым
rmdir empty/                       # удалить пустую папку
```

В командной строке **нет корзины**. Удалённый файл не восстановить.

Самая известная опасная команда — `rm -rf`. Опция `-f` отключает все вопросы
и предупреждения. Одна опечатка в пути — и исчезнет не то.

Привычки, которые берегут данные:

- перед удалением по шаблону сначала выполни `ls` с тем же шаблоном;
- никогда не запускай `rm -rf` с переменной в пути, не проверив её значение;
- используй `rm -i`, пока не появится уверенность.

## Шаблоны имён

Оболочка умеет подставлять вместо шаблона список подходящих файлов.

| Шаблон | Что означает | Пример | Чему соответствует |
|---|---|---|---|
| `*` | любое количество любых символов | `*.log` | все файлы с расширением .log |
| `?` | ровно один любой символ | `sw-?.cfg` | `sw-1.cfg`, `sw-a.cfg` |
| `[abc]` | один символ из набора | `sw-[12].cfg` | `sw-1.cfg`, `sw-2.cfg` |
| `{a,b}` | один из вариантов | `{sw,rt}-1.cfg` | `sw-1.cfg`, `rt-1.cfg` |

```bash
ls *.txt                  # все текстовые файлы
cp *.cfg backup/          # скопировать все конфигурации
rm sw-?.log               # удалить sw-1.log, sw-2.log, но не sw-10.log
mkdir -p lab/{configs,logs,scripts}   # создать сразу три папки
```

Шаблон раскрывает оболочка, а не команда. Команда `ls *.txt` получает
уже готовый список имён.

## Поиск: find

`find` ищет файлы в указанной папке и во всех вложенных.

```bash
find . -name "*.py"                # по имени, начиная с текущей папки
find ~ -iname "*README*"           # без учёта регистра
find /etc -type d -name "ssh*"     # только папки (d — directory)
find . -type f -size +10M          # файлы больше 10 мегабайт
find . -mtime -1                   # изменённые за последние сутки
```

Шаблон в `find` пиши в кавычках. Иначе оболочка раскроет его раньше,
чем он попадёт к команде.

С найденным можно сразу что-то сделать:

```bash
find . -name "*.tmp" -delete       # найти и удалить
```

Сначала запусти ту же команду без `-delete` и посмотри, что нашлось.

## Информация о файлах

```bash
ls -lh                    # размеры в понятном виде: 4.0K, 12M
du -sh projects/          # сколько места занимает папка целиком
df -h                     # свободное место на дисках
file photo.jpg            # что это за файл на самом деле
wc -l notes.txt           # количество строк в файле
```

В Linux расширение — лишь часть имени. Команда `file` определяет тип
по содержимому.

## Как устроено дерево каталогов

В Windows есть диски C: и D:. В Linux одно дерево, которое растёт от корня `/`.

| Каталог | Что в нём |
|---|---|
| `/home` | домашние папки пользователей |
| `/etc` | настройки системы и программ |
| `/var` | изменяющиеся данные; логи лежат в `/var/log` |
| `/tmp` | временные файлы, очищается при перезагрузке |
| `/usr` | установленные программы и библиотеки |
| `/bin`, `/sbin` | основные системные команды |
| `/root` | домашняя папка администратора |
| `/mnt` | точки подключения дисков; в WSL диск C: виден как `/mnt/c` |

Как сетевой инженер ты будешь часто заглядывать в `/etc` (там настройки сети,
SSH, DNS) и в `/var/log`.
