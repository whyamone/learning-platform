# Теория

## Модуль — это файл

Любой файл с расширением `.py` является модулем. Чтобы воспользоваться
кодом из другого файла, его подключают словом `import`.

```python
import math

print(math.sqrt(16))     # 4.0 — квадратный корень
print(math.pi)           # 3.141592653589793
print(math.ceil(4.1))    # 5 — округление вверх
```

После `import math` всё содержимое модуля доступно через точку.

## Три способа импорта

```python
import random                    # весь модуль, обращение через имя модуля
print(random.randint(1, 6))

from random import randint       # только нужная функция, без префикса
print(randint(1, 6))

import datetime as dt            # модуль под коротким именем
print(dt.date.today())
```

Все импорты принято писать в самом начале файла. Вариант
`from module import *` (импортировать всё) лучше не использовать: непонятно,
откуда взялось имя.

## Стандартная библиотека

Вместе с Python устанавливаются сотни модулей. Несколько полезных:

| Модуль | Для чего |
|---|---|
| `math` | математика |
| `random` | случайные числа |
| `datetime` | дата и время |
| `pathlib` | пути к файлам |
| `json` | формат JSON |
| `ipaddress` | IP-адреса и подсети |
| `collections` | дополнительные структуры данных |

Как сетевому инженеру тебе понравится `ipaddress`:

```python
import ipaddress

network = ipaddress.ip_network("192.168.1.0/26")

print(network.netmask)             # 255.255.255.192
print(network.num_addresses)       # 64
print(network.broadcast_address)   # 192.168.1.63

address = ipaddress.ip_address("192.168.1.10")
print(address in network)          # True
print(address.is_private)          # True
```

Прежде чем писать что-то своё, проверь, нет ли готового в стандартной библиотеке.

## Свой модуль

Создай файл `netutils.py`:

```python
def is_valid_vlan(number):
    """Проверить, что номер VLAN лежит в допустимом диапазоне."""
    return 1 <= number <= 4094
```

Рядом создай `main.py`:

```python
from netutils import is_valid_vlan

print(is_valid_vlan(100))     # True
```

Python ищет модуль в той же папке, откуда запущена программа.

## if __name__ == "__main__"

При импорте Python выполняет весь файл модуля. Если в `netutils.py` на верхнем
уровне стоит `print()`, он сработает и при импорте. Чтобы код выполнялся только
при прямом запуске файла, его помещают под специальное условие:

```python
def is_valid_vlan(number):
    return 1 <= number <= 4094


if __name__ == "__main__":
    # Этот блок выполнится при запуске `python3 netutils.py`
    # и НЕ выполнится при `import netutils`.
    print(is_valid_vlan(100))
```

Переменная `__name__` равна `"__main__"`, когда файл запущен напрямую,
и имени модуля — когда он импортирован.

## Сторонние библиотеки и pip

Библиотеки, которых нет в стандартной поставке, лежат в каталоге PyPI.
Их устанавливает программа `pip`.

Но ставить библиотеки прямо в систему нельзя. Ubuntu сама использует Python
и не даст это сделать, а разным проектам нужны разные версии одних библиотек.
Решение — виртуальное окружение.

## Виртуальное окружение

Это отдельная папка с собственной копией Python и своими библиотеками.
У каждого проекта — своё окружение.

Один раз установи поддержку окружений:

```bash
sudo apt install -y python3-venv
```

Создай окружение в папке проекта:

```bash
mkdir -p ~/study/python/netcheck
cd ~/study/python/netcheck
python3 -m venv .venv
```

Появится папка `.venv`. Теперь окружение нужно активировать:

```bash
source .venv/bin/activate
```

В начале строки приглашения появится `(.venv)` — признак, что окружение включено.
Внутри него команды `python` и `pip` относятся к этому окружению.

Устанавливаем библиотеку:

```bash
pip install rich
```

Проверяем:

```python
from rich import print

print("[bold green]Успех![/bold green] Библиотека работает")
```

Выйти из окружения — команда `deactivate`.

> Активировать окружение нужно в каждом новом окне терминала. Если Python
> пишет `ModuleNotFoundError`, первым делом проверь, есть ли `(.venv)` в приглашении.

## Файл requirements.txt

Папку `.venv` не копируют и не отправляют в git: она большая и привязана
к компьютеру. Вместо этого сохраняют список установленных библиотек.

```bash
pip freeze > requirements.txt
```

На другом компьютере окружение воссоздаётся тремя командами:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

Именно так устроен проект этой учебной платформы: открой её `requirements.txt`
и увидишь список библиотек с версиями.

## Полезные команды pip

| Команда | Что делает |
|---|---|
| `pip install имя` | установить библиотеку |
| `pip install имя==1.2.3` | установить конкретную версию |
| `pip uninstall имя` | удалить |
| `pip list` | показать установленные |
| `pip show имя` | сведения о библиотеке |
