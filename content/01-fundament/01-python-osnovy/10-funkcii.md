# Теория

## Зачем нужны функции

Ты уже пользуешься функциями: `print()`, `len()`, `input()`. Функция — это
кусок кода с именем. Написал один раз — вызываешь где угодно.

Что это даёт:

- **Нет повторений.** Нашёл ошибку — исправил в одном месте.
- **Понятность.** `is_valid_ip(address)` читается лучше десяти строк проверок.
- **Проверяемость.** Маленькую функцию легко проверить отдельно.

## Объявление и вызов

```python
def greet():
    print("Привет!")
    print("Добро пожаловать")

greet()      # вызов: код функции выполняется
greet()      # можно вызывать сколько угодно раз
```

`def` объявляет функцию, но не выполняет её. Код внутри сработает только
при вызове — когда после имени стоят скобки.

## Параметры

Параметры — это данные, которые функция получает на вход.

```python
def describe(hostname, ports):
    print(f"Устройство {hostname}, портов: {ports}")

describe("sw-1", 24)
describe("sw-2", 48)
```

`hostname` и `ports` в объявлении — **параметры**. Значения `"sw-1"` и `24`
при вызове — **аргументы**. Аргументы подставляются по порядку.

## return — вернуть результат

```python
def to_megabytes(size_bytes):
    return size_bytes / 1024 / 1024

size = to_megabytes(5_000_000)
print(f"{size:.2f} МБ")           # 4.77 МБ
print(to_megabytes(1024 * 1024))  # 1.0
```

`return` делает две вещи: завершает функцию и передаёт значение туда,
откуда её вызвали. Результат можно сохранить в переменную или сразу использовать.

## print() и return — не одно и то же

Это главное, что нужно понять в теме.

```python
def add_print(a, b):
    print(a + b)        # только показывает на экране

def add_return(a, b):
    return a + b        # отдаёт значение программе

x = add_print(2, 3)     # на экране 5, но x = None
y = add_return(2, 3)    # на экране ничего, но y = 5

print(x)    # None
print(y)    # 5
```

`print()` — для человека. `return` — для программы. Функция без `return`
возвращает специальное значение `None` («ничего»).

Хорошая привычка: функция **вычисляет и возвращает**, а печатает тот, кто её вызвал.

## Несколько return

```python
def port_service(port):
    if port == 22:
        return "SSH"
    if port == 443:
        return "HTTPS"
    return "неизвестно"

print(port_service(22))      # SSH
print(port_service(8080))    # неизвестно
```

Как только выполнился `return`, функция завершается. Поэтому `else` здесь не нужен.

Функция может вернуть несколько значений — на самом деле это кортеж:

```python
def min_max(numbers):
    return min(numbers), max(numbers)

low, high = min_max([45, 92, 13, 78])
print(low, high)     # 13 92
```

## Значения по умолчанию

```python
def connect(host, port=22, timeout=10):
    print(f"Подключение к {host}:{port}, таймаут {timeout} сек")

connect("10.0.0.1")                  # порт и таймаут по умолчанию
connect("10.0.0.1", 2222)            # свой порт
connect("10.0.0.1", timeout=30)      # именованный аргумент
```

Параметры со значением по умолчанию идут после обязательных.
Именованные аргументы (`timeout=30`) можно передавать в любом порядке —
и код с ними понятнее.

## Область видимости

Переменные, созданные внутри функции, существуют только внутри неё.

```python
def calculate():
    result = 42
    return result

calculate()
print(result)
```

```text
NameError: name 'result' is not defined
```

Это полезное свойство: функции не мешают друг другу, даже если в них
одинаковые имена переменных. Данные входят через параметры, выходят через `return`.

Функция может **читать** переменные, объявленные снаружи. Но лучше
так не делать: функция, которая зависит только от своих параметров,
предсказуема и легко проверяется.

## Строка документации

Сразу под `def` можно написать пояснение в тройных кавычках.

```python
def is_private_ip(ip):
    """Проверить, относится ли адрес к частной сети 10.0.0.0/8."""
    return ip.startswith("10.")
```

Это называется docstring. Такой текст показывают редакторы кода и функция `help()`.

## Функция как значение

Имя функции без скобок — это сама функция. Её можно передать в другую функцию.

```python
devices = [
    {"hostname": "sw-2", "ports": 48},
    {"hostname": "sw-1", "ports": 24},
]

def get_ports(device):
    return device["ports"]

devices.sort(key=get_ports)     # сортировать по результату get_ports
print(devices[0]["hostname"])   # sw-1
```

Для таких коротких функций есть запись `lambda`:

```python
devices.sort(key=lambda device: device["ports"])
```

`lambda device: device["ports"]` — безымянная функция: принимает `device`,
возвращает `device["ports"]`.

## Как делить программу на функции

Признаки хорошей функции:

- делает **одно** дело, и это дело описывается её именем;
- имя начинается с глагола: `parse_line`, `count_errors`, `is_valid_ip`;
- помещается на экран;
- не спрашивает данные через `input()` и не печатает, а получает параметры
  и возвращает результат.

Типичная структура программы:

```python
def parse_line(line):
    """Разобрать строку лога на части."""
    parts = line.split()
    return {"host": parts[0], "level": parts[1], "message": " ".join(parts[2:])}


def count_errors(records):
    """Посчитать записи уровня ERROR."""
    return sum(1 for record in records if record["level"] == "ERROR")


def main():
    lines = ["sw-1 ERROR port down", "sw-2 INFO link up", "sw-1 ERROR fan failure"]
    records = [parse_line(line) for line in lines]
    print(f"Ошибок: {count_errors(records)}")


main()
```

Ввод и вывод собраны в `main()`, а остальные функции занимаются только расчётами.
