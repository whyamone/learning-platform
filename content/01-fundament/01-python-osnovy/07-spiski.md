# Теория

## Что такое список

Список хранит несколько значений по порядку. Записывается в квадратных скобках.

```python
vlans = [10, 20, 30, 99]
hosts = ["sw-1", "sw-2", "router-1"]
mixed = ["sw-1", 24, True]      # типы можно смешивать, но обычно так не делают
empty = []

print(len(vlans))     # 4 — количество элементов
```

## Индексы и срезы

Работают так же, как у строк: счёт с нуля, отрицательные индексы — с конца.

```python
hosts = ["sw-1", "sw-2", "router-1", "fw-1"]

print(hosts[0])      # sw-1
print(hosts[-1])     # fw-1
print(hosts[1:3])    # ['sw-2', 'router-1']
```

## Списки можно изменять

В отличие от строк, список — **изменяемый** тип.

```python
vlans = [10, 20, 30]
vlans[0] = 100
print(vlans)         # [100, 20, 30]
```

## Добавление и удаление

```python
vlans = [10, 20]

vlans.append(30)         # добавить в конец           → [10, 20, 30]
vlans.insert(0, 5)       # вставить на позицию 0      → [5, 10, 20, 30]
vlans.extend([40, 50])   # добавить несколько сразу   → [5, 10, 20, 30, 40, 50]

vlans.remove(20)         # удалить по значению        → [5, 10, 30, 40, 50]
last = vlans.pop()       # удалить последний и вернуть его: last = 50
first = vlans.pop(0)     # удалить по индексу: first = 5
del vlans[0]             # удалить по индексу без возврата

print(vlans)             # [30, 40]
```

> Методы списка меняют сам список и ничего не возвращают. Частая ошибка —
> написать `vlans = vlans.append(30)`: в переменной окажется `None`.
> Сравни со строками, где метод возвращает новую строку.

## Перебор в цикле

```python
hosts = ["sw-1", "sw-2", "router-1"]

for host in hosts:
    print(f"Проверяю {host}")
```

Если нужен ещё и номер, используй `enumerate()`:

```python
for number, host in enumerate(hosts, start=1):
    print(f"{number}. {host}")
```

```text
1. sw-1
2. sw-2
3. router-1
```

## Полезные функции и операции

```python
loads = [45, 92, 13, 78]

print(len(loads))      # 4   количество
print(sum(loads))      # 228 сумма
print(min(loads))      # 13  минимум
print(max(loads))      # 92  максимум
print(sum(loads) / len(loads))   # 57.0 среднее

print(92 in loads)     # True — есть ли значение в списке
print(loads.index(92)) # 1 — на какой позиции
print(loads.count(13)) # 1 — сколько раз встречается
```

## Сортировка

```python
loads = [45, 92, 13, 78]

loads.sort()                    # сортирует сам список
print(loads)                    # [13, 45, 78, 92]

loads.sort(reverse=True)        # по убыванию
print(loads)                    # [92, 78, 45, 13]

names = ["sw-2", "router-1", "sw-1"]
print(sorted(names))            # возвращает НОВЫЙ список, исходный не меняет
```

Разница: `список.sort()` меняет список на месте, `sorted(список)` создаёт новый.

## Ловушка: две переменные — один список

```python
a = [1, 2, 3]
b = a            # это НЕ копия
b.append(4)

print(a)         # [1, 2, 3, 4] — изменился и a
```

Вспомни сравнение с наклейками: `b = a` клеит вторую наклейку на ту же коробку.
Чтобы получить независимую копию, используй `a.copy()`:

```python
a = [1, 2, 3]
b = a.copy()
b.append(4)
print(a)         # [1, 2, 3]
```

## Генератор списка

Частая задача: построить новый список на основе старого. Обычный способ:

```python
ports = [1, 2, 3, 4]
names = []
for port in ports:
    names.append(f"Gi0/{port}")
```

То же самое одной строкой — **генератор списка** (list comprehension):

```python
names = [f"Gi0/{port}" for port in ports]
print(names)     # ['Gi0/1', 'Gi0/2', 'Gi0/3', 'Gi0/4']
```

Читается так: «возьми `f"Gi0/{port}"` для каждого `port` из `ports`».
В конец можно добавить условие-фильтр:

```python
loads = [45, 92, 13, 78]
high = [load for load in loads if load > 70]
print(high)      # [92, 78]
```

Не старайся писать так сразу. Сначала обычный цикл, а когда он станет привычным —
короткая запись.

## Список списков

Элементом списка может быть другой список — получается таблица.

```python
table = [
    ["sw-1", "192.168.1.1", 24],
    ["sw-2", "192.168.1.2", 48],
]

print(table[1][0])      # sw-2 — вторая строка, первый столбец

for name, ip, ports in table:
    print(f"{name:10} {ip:15} {ports}")
```

Запись `for name, ip, ports in table` сразу раскладывает каждую строку
по трём переменным.
