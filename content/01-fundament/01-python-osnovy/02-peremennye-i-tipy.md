# Теория

## Что такое переменная

Переменная — это имя, к которому привязано значение. Представь наклейку
с надписью, которую приклеили на коробку: по надписи всегда найдёшь содержимое.

```python
hostname = "router-1"
port_count = 24

print(hostname)
print(port_count)
```

Знак `=` в Python означает не «равно», а **«присвоить»**: вычисли то, что справа,
и привяжи результат к имени слева. Читай `port_count = 24` как
«имя port_count теперь указывает на 24».

Значение можно менять — потому переменная так и называется:

```python
port_count = 24
port_count = 48          # старое значение забыто
port_count = port_count + 2   # взяли текущее (48), прибавили 2, записали обратно
print(port_count)        # 50
```

Последнюю операцию можно записать короче: `port_count += 2`.
Так же работают `-=`, `*=`, `/=`.

## Правила имён

- Только латинские буквы, цифры и знак подчёркивания.
- Имя не может начинаться с цифры.
- Регистр важен: `port` и `Port` — разные переменные.
- Нельзя использовать служебные слова Python: `if`, `for`, `class` и другие.

В Python принят стиль `snake_case` — слова маленькими буквами через подчёркивание.

| Плохо | Хорошо | Почему |
|---|---|---|
| `a`, `x1` | `port_count` | Имя должно объяснять, что хранится |
| `PortCount` | `port_count` | Принятый стиль для переменных |
| `kolvo` | `count` | Имена принято писать по-английски |

## Основные типы данных

У каждого значения есть **тип**. Тип определяет, что с этим значением можно делать.

| Тип | Что это | Примеры |
|---|---|---|
| `int` | целое число | `24`, `-5`, `0` |
| `float` | дробное число | `3.14`, `-0.5`, `2.0` |
| `str` | строка (текст) | `"router-1"`, `'привет'` |
| `bool` | логическое значение | `True`, `False` |

Узнать тип можно функцией `type()`:

```python
print(type(24))          # <class 'int'>
print(type(3.14))        # <class 'float'>
print(type("router-1"))  # <class 'str'>
print(type(True))        # <class 'bool'>
```

> Дробная часть отделяется точкой, а не запятой: `3.14`. А `True` и `False`
> пишутся с заглавной буквы и без кавычек.

Тип указывать не нужно — Python определяет его сам по значению.

## Арифметика

```python
print(7 + 2)    # 9    сложение
print(7 - 2)    # 5    вычитание
print(7 * 2)    # 14   умножение
print(7 / 2)    # 3.5  деление — результат всегда float
print(7 // 2)   # 3    целочисленное деление: дробная часть отбрасывается
print(7 % 2)    # 1    остаток от деления
print(7 ** 2)   # 49   возведение в степень
```

Операции `//` и `%` встречаются чаще, чем кажется. Пример: перевести секунды
в минуты и секунды.

```python
uptime = 200                 # время работы в секундах
minutes = uptime // 60       # 3 — сколько полных минут
seconds = uptime % 60        # 20 — сколько секунд осталось
print(minutes, "мин", seconds, "сек")
```

Порядок действий как в математике: сначала `**`, затем `*`, `/`, `//`, `%`,
в конце `+` и `-`. Скобки меняют порядок:

```python
print(2 + 3 * 4)     # 14
print((2 + 3) * 4)   # 20
```

## Тип влияет на поведение

Один и тот же знак работает по-разному с числами и со строками:

```python
print(2 + 3)         # 5 — числа складываются
print("2" + "3")     # 23 — строки склеиваются
print("ab" * 3)      # ababab — строка повторяется
```

А вот смешивать типы нельзя:

```python
print("Портов: " + 24)
```

```text
TypeError: can only concatenate str (not "int") to str
```

Python не станет гадать, что ты имел в виду. Как превращать один тип в другой —
в следующей теме.

## Особенность дробных чисел

```python
print(0.1 + 0.2)   # 0.30000000000000004
```

Это не ошибка Python. Компьютер хранит дробные числа в двоичном виде, и некоторые
из них представляются неточно — как 1/3 нельзя точно записать десятичной дробью.
Для вывода результат округляют: `round(0.1 + 0.2, 2)` даст `0.3`.
