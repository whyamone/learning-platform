# Теория

## Сравнения

Результат сравнения — значение типа `bool`: `True` (правда) или `False` (ложь).

```python
print(5 > 3)      # True
print(5 == 3)     # False
print(5 != 3)     # True
```

| Оператор | Значение |
|---|---|
| `==` | равно |
| `!=` | не равно |
| `>` , `<` | больше, меньше |
| `>=`, `<=` | больше или равно, меньше или равно |

> Самая частая ошибка новичка: `=` присваивает, а `==` сравнивает.
> `x = 5` — записать 5 в x. `x == 5` — спросить, равен ли x пяти.

Строки тоже можно сравнивать. Регистр букв имеет значение:

```python
print("up" == "up")    # True
print("up" == "UP")    # False
```

## Оператор if

```python
load = 92

if load > 90:
    print("Внимание: высокая загрузка")
    print("Проверь устройство")

print("Проверка завершена")
```

Как это читается: если условие истинно, выполнить блок под ним.
Строка `Проверка завершена` напечатается в любом случае — она не входит в блок.

## Отступы — часть языка

Блок кода, относящийся к `if`, выделяется **отступом** в четыре пробела.
В Python отступы не украшение: по ним интерпретатор понимает, где блок
начинается и заканчивается.

```python
if load > 90:
print("Высокая загрузка")
```

```text
IndentationError: expected an indented block after 'if' statement on line 1
```

Запомни два правила: после условия ставится двоеточие, блок под ним сдвигается
на четыре пробела.

## else — что делать, если условие ложно

```python
status = "down"

if status == "up":
    print("Интерфейс работает")
else:
    print("Интерфейс не работает")
```

Выполнится ровно одна из двух веток.

## elif — несколько вариантов

```python
load = 75

if load >= 90:
    print("Критично")
elif load >= 70:
    print("Повышенная загрузка")
elif load >= 40:
    print("Норма")
else:
    print("Устройство почти не занято")
```

Python проверяет условия сверху вниз и выполняет **первую** подходящую ветку.
Остальные пропускаются, даже если их условия тоже истинны. Поэтому порядок важен:
начни с `load >= 40`, и для значения 95 сработает именно эта ветка.

## Логические операторы

Несколько условий объединяются словами `and`, `or`, `not`.

| Оператор | Истинно, когда |
|---|---|
| `a and b` | истинны оба условия |
| `a or b` | истинно хотя бы одно |
| `not a` | условие ложно |

```python
port = 443
is_encrypted = True

if port == 443 and is_encrypted:
    print("Защищённое соединение")

if port == 80 or port == 8080:
    print("Обычный HTTP")

if not is_encrypted:
    print("Данные передаются открыто")
```

Проверку диапазона в Python можно записать как в математике:

```python
vlan = 150
if 1 <= vlan <= 4094:
    print("Допустимый номер VLAN")
```

## Вложенные условия

Условие можно поместить внутрь другого. Каждый уровень — ещё четыре пробела.

```python
is_admin = True
password_ok = False

if is_admin:
    if password_ok:
        print("Доступ разрешён")
    else:
        print("Неверный пароль")
else:
    print("Нужны права администратора")
```

Глубокую вложенность трудно читать. Часто её можно заменить на `and`:
`if is_admin and password_ok:`.

## Что считается истиной

В условии можно писать не только сравнение, но и само значение.
Python считает ложными: `0`, пустую строку `""`, `None` и пустые коллекции.
Всё остальное — истина.

```python
name = input("Имя устройства: ")

if name:
    print(f"Устройство: {name}")
else:
    print("Имя не указано")
```

Здесь `if name:` означает «если строка не пустая».

# Практика

**Задание 1.** Программа спрашивает число и сообщает, положительное оно,
отрицательное или ноль.

**Задание 2.** Программа запрашивает номер порта (число) и выводит название
сервиса: 22 — SSH, 53 — DNS, 80 — HTTP, 443 — HTTPS. Для остальных номеров —
«Неизвестный сервис».

**Задание 3.** Программа запрашивает номер VLAN. Если он от 1 до 1005 — вывести
«обычный диапазон», от 1006 до 4094 — «расширенный диапазон», иначе —
«недопустимый номер».

**Задание 4.** Программа просит первый октет IP-адреса и определяет, частный ли
это адрес по упрощённому правилу: 10 — частный, 172 — возможно частный,
192 — возможно частный, остальные — публичный.

**Задание 5.** Программа спрашивает год и отвечает, високосный ли он. Год
високосный, если делится на 4, но не делится на 100, либо делится на 400.
Проверь на годах 1900, 2000, 2024, 2025.

**Задание 6 (со звёздочкой).** Программа запрашивает загрузку процессора
и памяти в процентах. Если оба показателя выше 90 — «авария»; если выше 90
только один — «предупреждение» с указанием, какой именно; иначе — «норма».
