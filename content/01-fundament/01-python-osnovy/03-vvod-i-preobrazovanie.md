# Теория

## Функция input()

`input()` останавливает программу и ждёт, пока пользователь наберёт текст
и нажмёт Enter. Введённое возвращается как значение.

```python
name = input("Как тебя зовут? ")
print("Привет,", name)
```

Текст в скобках — подсказка, которую увидит пользователь. Пробел в конце
подсказки нужен, чтобы ввод не прилипал к вопросу.

## input() всегда возвращает строку

Это главная ловушка темы:

```python
count = input("Сколько портов? ")   # пользователь ввёл 24
print(count * 2)                    # 2424, а не 48
```

Пользователь набрал цифры, но для Python это строка `"24"`. А строка,
умноженная на 2, просто повторяется дважды.

## Преобразование типов

Чтобы превратить значение в другой тип, используют функции с именем типа:

| Функция | Что делает | Пример | Результат |
|---|---|---|---|
| `int()` | в целое число | `int("24")` | `24` |
| `float()` | в дробное число | `float("3.5")` | `3.5` |
| `str()` | в строку | `str(24)` | `"24"` |

Исправленный пример:

```python
count = int(input("Сколько портов? "))
print(count * 2)    # 48
```

Читай изнутри наружу: сначала `input()` получает строку, затем `int()`
превращает её в число, и результат записывается в `count`.

Ещё несколько полезных случаев:

```python
print(int(3.9))       # 3 — дробная часть отбрасывается, а не округляется
print(round(3.9))     # 4 — а так округляется
print(float(5))       # 5.0
print(int("  42  "))  # 42 — пробелы по краям не мешают
```

## Если ввели не число

```python
int("двадцать")
```

```text
ValueError: invalid literal for int() with base 10: 'двадцать'
```

`ValueError` означает: тип подходящий (строка), а значение — нет.
Пока просто знай, откуда эта ошибка. Обрабатывать её научимся в теме про исключения.

## f-строки

Выводить значения через запятую в `print()` не всегда удобно. Лучший способ —
f-строка: перед кавычками ставится буква `f`, а переменные пишутся в фигурных скобках.

```python
hostname = "sw-core-1"
ports = 48
print(f"Коммутатор {hostname}: портов {ports}")
```

Внутри скобок можно писать вычисления:

```python
print(f"Свободно портов: {ports - 12}")
```

После двоеточия задаётся формат вывода:

```python
load = 73.4567
print(f"Загрузка: {load:.1f}%")     # Загрузка: 73.5% — один знак после запятой
print(f"Загрузка: {load:.0f}%")     # Загрузка: 73%

traffic = 1234567
print(f"Передано: {traffic:,} байт")  # Передано: 1,234,567 байт
```

`.1f` читается так: один знак после точки, тип `f` — дробное число.

## Параметры print()

По умолчанию `print()` разделяет значения пробелом и в конце переходит
на новую строку. Это можно изменить:

```python
print("192", "168", "1", "1", sep=".")   # 192.168.1.1
print("Загрузка...", end=" ")
print("готово")                          # Загрузка... готово
```

## Собираем всё вместе

```python
# Программа считает, сколько времени займёт передача файла.
size_mb = float(input("Размер файла, МБ: "))
speed_mbit = float(input("Скорость канала, Мбит/с: "))

speed_mb = speed_mbit / 8          # мегабайт в секунду
seconds = size_mb / speed_mb

print(f"Передача займёт {seconds:.1f} сек ({seconds / 60:.1f} мин)")
```

У большинства простых программ три части: получить данные, обработать, вывести.
