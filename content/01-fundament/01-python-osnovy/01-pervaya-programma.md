# Теория

## Что такое программа

Программа — это текст с инструкциями для компьютера. Инструкции выполняются
по порядку, сверху вниз, одна за другой.

Компьютер не понимает текст напрямую. Между твоим текстом и компьютером стоит
**интерпретатор** — программа, которая читает код строку за строкой и выполняет его.
Когда говорят «установить Python», имеют в виду установить интерпретатор.

## Проверяем, что Python установлен

Открой терминал Ubuntu (тот, что появился после установки WSL) и набери:

```bash
python3 --version
```

В ответ появится что-то вроде `Python 3.12.3`. Точные цифры могут отличаться —
важно, чтобы версия начиналась с 3.

> В Ubuntu команда называется `python3`, а не `python`. Это частая причина
> ошибки «command not found» у новичков.

## Способ 1: интерактивный режим

Набери в терминале:

```bash
python3
```

Появится приглашение `>>>`. Это интерактивный режим: пишешь строку кода, жмёшь
Enter — и сразу видишь результат. Его ещё называют REPL.

```python
>>> 2 + 2
4
>>> print("Привет!")
Привет!
```

Чтобы выйти, набери `exit()` или нажми `Ctrl+D`.

Интерактивный режим хорош для быстрых проверок: «а что будет, если…».
Но код в нём не сохраняется.

## Способ 2: программа в файле

Настоящие программы хранят в файлах с расширением `.py`.

Создай папку для учебных программ и перейди в неё:

```bash
mkdir -p ~/study/python
cd ~/study/python
```

Создай файл в текстовом редакторе `nano`:

```bash
nano hello.py
```

Набери в нём одну строку:

```python
print("Привет, мир!")
```

Сохрани (`Ctrl+O`, затем Enter) и выйди (`Ctrl+X`). Теперь запусти:

```bash
python3 hello.py
```

На экране появится `Привет, мир!`. Это твоя первая программа.

## Функция print()

`print()` выводит на экран то, что указано в скобках.

```python
print("Текст пишется в кавычках")
print('Одинарные кавычки тоже подходят')
print(2 + 3)            # число и вычисления — без кавычек
print("2 + 3")          # в кавычках это просто текст, он не вычисляется
print("Ответ:", 2 + 3)  # несколько значений через запятую
```

Результат:

```text
Текст пишется в кавычках
Одинарные кавычки тоже подходят
5
2 + 3
Ответ: 5
```

Текст в кавычках называется **строкой**. Запомни разницу: `2 + 3` — вычисление,
`"2 + 3"` — строка из пяти символов.

## Комментарии

Всё, что написано после символа `#`, Python пропускает. Это заметки для человека.

```python
# Эта строка ничего не делает
print("А эта выполняется")  # комментарий можно писать и в конце строки
```

Комментарии объясняют, **зачем** написан код. Через месяц ты сам себе скажешь спасибо.

## Ошибки — это нормально

Ошибаться будешь постоянно, как и все программисты. Важно научиться читать
сообщение об ошибке. Попробуй запустить файл с такой строкой:

```python
print("Привет)
```

Python ответит примерно так:

```text
  File "hello.py", line 1
    print("Привет)
          ^
SyntaxError: unterminated string literal (detected at line 1)
```

Как читать:

1. `line 1` — номер строки, где Python споткнулся.
2. `^` показывает место в строке.
3. Последняя строка — тип ошибки и описание. `SyntaxError` значит, что нарушены
   правила записи: здесь не закрыта кавычка.

Три ошибки, которые встретишь первыми:

| Сообщение | Причина |
|---|---|
| `SyntaxError` | Опечатка в записи: забыта кавычка или скобка |
| `NameError: name 'prnt' is not defined` | Опечатка в имени: написал `prnt` вместо `print` |
| `IndentationError` | Лишние пробелы в начале строки |
