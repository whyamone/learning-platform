# Теория

## Зачем нужны циклы

Вывести числа от 1 до 5 можно пятью строками `print()`. А от 1 до 1000?
Цикл позволяет написать действие один раз и повторить его сколько угодно.

## Цикл while

`while` повторяет блок, **пока условие истинно**.

```python
attempt = 1

while attempt <= 3:
    print(f"Попытка подключения №{attempt}")
    attempt += 1

print("Попытки закончились")
```

Как это работает по шагам:

1. Проверить условие `attempt <= 3`.
2. Если истинно — выполнить блок и вернуться к шагу 1.
3. Если ложно — перейти к коду после цикла.

Один проход цикла называется **итерацией**.

## Бесконечный цикл

Если условие никогда не станет ложным, цикл не закончится:

```python
attempt = 1
while attempt <= 3:
    print("Попытка")     # забыли attempt += 1
```

Программа будет печатать без остановки. Прервать её можно клавишами `Ctrl+C`.
Если программа «зависла», первым делом проверь: меняется ли внутри цикла то,
от чего зависит условие.

## Цикл for

`for` перебирает элементы по очереди. Самый простой источник элементов —
`range()`, который выдаёт числа.

```python
for number in range(5):
    print(number)
```

```text
0
1
2
3
4
```

Обрати внимание: счёт начинается с нуля, а само число 5 не входит.
`range(5)` — это пять чисел: от 0 до 4.

| Запись | Какие числа | Пояснение |
|---|---|---|
| `range(5)` | 0, 1, 2, 3, 4 | от нуля до 5, не включая 5 |
| `range(1, 6)` | 1, 2, 3, 4, 5 | от 1 до 6, не включая 6 |
| `range(0, 10, 2)` | 0, 2, 4, 6, 8 | с шагом 2 |
| `range(5, 0, -1)` | 5, 4, 3, 2, 1 | в обратную сторону |

Имя переменной цикла (`number`) выбираешь сам. На каждой итерации в неё
попадает следующее число.

```python
for port in range(1, 5):
    print(f"interface GigabitEthernet0/{port}")
```

`for` умеет перебирать не только числа. Строку он перебирает по символам:

```python
for letter in "VLAN":
    print(letter)
```

## for или while

- **for** — когда заранее известно, что перебирать: числа от 1 до 10,
  символы строки, элементы списка.
- **while** — когда неизвестно, сколько повторений понадобится:
  «спрашивай пароль, пока не введут верный».

## Счётчик и накопитель

Два приёма, которые встречаются почти в каждой программе.

```python
total = 0          # накопитель: сюда складываем
count = 0          # счётчик: считаем количество

for number in range(1, 11):
    if number % 2 == 0:          # только чётные
        total += number
        count += 1

print(f"Чётных чисел: {count}, их сумма: {total}")
```

Важно: переменные создаются **до** цикла. Если написать `total = 0` внутри,
значение будет сбрасываться на каждой итерации.

## break — выйти из цикла досрочно

```python
secret = "cisco123"

while True:                       # условие всегда истинно
    password = input("Пароль: ")
    if password == secret:
        print("Доступ разрешён")
        break                     # выходим из цикла
    print("Неверно, попробуй ещё")
```

Конструкция `while True` с `break` внутри — обычный способ записать
«повторяй, пока не случится нужное событие».

## continue — пропустить итерацию

```python
for vlan in range(1, 8):
    if vlan == 1:
        continue                  # VLAN 1 пропускаем
    print(f"Настраиваю VLAN {vlan}")
```

`continue` не завершает цикл, а сразу переходит к следующей итерации.

## Вложенные циклы

Цикл внутри цикла: на каждый шаг внешнего внутренний выполняется целиком.

```python
for switch in range(1, 3):
    for port in range(1, 4):
        print(f"Коммутатор {switch}, порт {port}")
```

Здесь шесть строк вывода: два коммутатора по три порта.
