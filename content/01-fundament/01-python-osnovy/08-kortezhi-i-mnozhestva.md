# Теория

## Кортеж

Кортеж похож на список, но его нельзя изменить после создания.
Записывается в круглых скобках.

```python
point = (10, 20)
server = ("192.168.1.10", 22)

print(server[0])       # 192.168.1.10 — индексы работают как у списка
print(len(server))     # 2
```

Попытка изменить элемент вызовет ошибку:

```python
server[1] = 2222
```

```text
TypeError: 'tuple' object does not support item assignment
```

Кортеж из одного элемента пишется с запятой: `(5,)`. Без запятой это просто
число в скобках.

## Зачем нужен кортеж, если есть список

- **Защита от случайного изменения.** Адрес и порт сервера — пара, которая
  не должна меняться по ходу программы.
- **Смысл.** Список — набор однотипных вещей, количество которых меняется.
  Кортеж — одна запись из фиксированного числа полей.
- Кортеж может быть ключом словаря, а список — нет (об этом в следующей теме).

## Распаковка

Значения кортежа можно разложить по переменным одной строкой:

```python
server = ("192.168.1.10", 22)
ip, port = server

print(ip)      # 192.168.1.10
print(port)    # 22
```

Количество переменных слева должно совпадать с числом элементов.
Этот же приём позволяет обменять значения двух переменных:

```python
a = 1
b = 2
a, b = b, a
print(a, b)    # 2 1
```

Распаковка работает и в цикле — ты уже видел это с `enumerate()`:

```python
servers = [("web", 80), ("ssh", 22), ("dns", 53)]

for name, port in servers:
    print(f"{name}: порт {port}")
```

## Множество

Множество хранит только **уникальные** значения и не помнит их порядок.
Записывается в фигурных скобках.

```python
vlans = {10, 20, 30, 20, 10}
print(vlans)           # {10, 20, 30} — повторения исчезли
print(len(vlans))      # 3
```

Пустое множество создаётся как `set()`. Запись `{}` — это пустой словарь.

Самое частое применение — убрать повторения из списка:

```python
ips = ["10.0.0.1", "10.0.0.2", "10.0.0.1", "10.0.0.3", "10.0.0.2"]
unique_ips = set(ips)
print(len(unique_ips))     # 3
print(sorted(unique_ips))  # обратно в отсортированный список
```

> У множества нет индексов: `vlans[0]` вызовет ошибку. Порядок элементов
> не гарантируется, поэтому «первого» элемента не существует.

## Изменение множества

```python
vlans = {10, 20}
vlans.add(30)          # добавить
vlans.add(10)          # уже есть — ничего не изменится
vlans.discard(20)      # удалить, если есть
print(vlans)           # {10, 30}
```

## Проверка вхождения

Оператор `in` работает и со списком, и с множеством. Но на множестве он
намного быстрее: в списке Python перебирает элементы по очереди,
в множестве находит нужный сразу. На тысячах элементов разница огромна.

```python
blocked = {"10.0.0.5", "10.0.0.9"}

if "10.0.0.5" in blocked:
    print("Адрес заблокирован")
```

## Операции над множествами

Здесь множества особенно удобны: сравнение двух наборов одной строкой.

```python
configured = {10, 20, 30, 40}     # VLAN в конфигурации
required = {20, 30, 50}           # VLAN по плану

print(configured & required)   # {20, 30}             пересечение: есть в обоих
print(configured | required)   # {10, 20, 30, 40, 50} объединение: всё вместе
print(configured - required)   # {10, 40}             лишние: есть, но не нужны
print(required - configured)   # {50}                 недостающие
```
