# Теория

## Что такое словарь

В списке значение находят по номеру. В словаре — по **ключу**, осмысленному имени.

```python
device = {
    "hostname": "sw-core-1",
    "ip": "192.168.1.1",
    "ports": 48,
    "is_active": True,
}

print(device["hostname"])    # sw-core-1
print(device["ports"])       # 48
```

Слева от двоеточия ключ, справа значение. Ключом обычно служит строка,
значением может быть что угодно.

Сравни с тем же в виде списка: `["sw-core-1", "192.168.1.1", 48, True]`.
Чтобы понять, что такое `device[2]`, придётся помнить порядок.
`device["ports"]` объясняет себя сам.

## Изменение словаря

```python
device = {"hostname": "sw-core-1", "ports": 48}

device["ports"] = 24            # изменить существующее значение
device["location"] = "стойка 3" # добавить новую пару — синтаксис тот же
del device["location"]          # удалить пару

print(device)
```

Ключи в словаре уникальны: запись по существующему ключу заменяет значение.

## Если ключа нет

```python
device = {"hostname": "sw-core-1"}
print(device["vendor"])
```

```text
KeyError: 'vendor'
```

Есть два способа избежать ошибки:

```python
# 1. Проверить заранее
if "vendor" in device:
    print(device["vendor"])

# 2. Метод get(): вернёт None или значение по умолчанию
print(device.get("vendor"))             # None
print(device.get("vendor", "неизвестно"))   # неизвестно
```

Правило: если ключ обязан быть — пиши `device["key"]`, и пусть ошибка сообщит
о проблеме. Если ключа может не быть — пиши `get()`.

## Перебор словаря

```python
device = {"hostname": "sw-core-1", "ip": "192.168.1.1", "ports": 48}

for key in device:                      # по ключам
    print(key)

for value in device.values():           # по значениям
    print(value)

for key, value in device.items():       # по парам — самый частый вариант
    print(f"{key}: {value}")
```

Порядок перебора совпадает с порядком добавления пар.

## Вложенные структуры

Значением может быть список или другой словарь. Так устроены почти все данные,
которые приходят из сети: ответы API, конфигурации, ответы нейросетей.

```python
device = {
    "hostname": "sw-core-1",
    "interfaces": [
        {"name": "Gi0/1", "status": "up", "vlan": 10},
        {"name": "Gi0/2", "status": "down", "vlan": 20},
    ],
    "location": {"room": "серверная", "rack": 3},
}

print(device["location"]["rack"])            # 3
print(device["interfaces"][0]["name"])       # Gi0/1

for interface in device["interfaces"]:
    print(f'{interface["name"]}: {interface["status"]}')
```

Длинное обращение читай слева направо, по одному шагу:
`device["interfaces"]` — список, `[0]` — его первый элемент (словарь),
`["name"]` — значение по ключу.

> Внутри f-строки в двойных кавычках ключи пишут в одинарных — и наоборот.
> Иначе Python решит, что строка закончилась раньше времени.

## Список словарей

Самый распространённый формат данных — таблица, где каждая строка это словарь.

```python
devices = [
    {"hostname": "sw-1", "vendor": "Cisco", "ports": 24},
    {"hostname": "sw-2", "vendor": "Eltex", "ports": 48},
    {"hostname": "sw-3", "vendor": "Cisco", "ports": 48},
]

cisco = [d for d in devices if d["vendor"] == "Cisco"]
total_ports = sum(d["ports"] for d in devices)

print(len(cisco))      # 2
print(total_ports)     # 120
```

## Подсчёт через словарь

Классическая задача: сколько раз встречается каждое значение.

```python
statuses = ["up", "down", "up", "up", "down", "up"]

counts = {}
for status in statuses:
    counts[status] = counts.get(status, 0) + 1

print(counts)     # {'up': 4, 'down': 2}
```

Разбор главной строки: `counts.get(status, 0)` берёт текущее количество
(или 0, если такого ключа ещё нет), прибавляет единицу и записывает обратно.

## Что может быть ключом

Ключом может быть только неизменяемое значение: строка, число, кортеж.
Список ключом быть не может.

```python
links = {("sw-1", "sw-2"): "10G", ("sw-2", "router-1"): "1G"}
print(links[("sw-1", "sw-2")])     # 10G
```
