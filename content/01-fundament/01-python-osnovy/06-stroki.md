# Теория

## Строка — последовательность символов

У каждого символа строки есть номер — **индекс**. Нумерация начинается с нуля.

```text
 s  w  -  c  o  r  e
 0  1  2  3  4  5  6     ← индексы слева
-7 -6 -5 -4 -3 -2 -1     ← индексы справа
```

```python
name = "sw-core"

print(name[0])     # s — первый символ
print(name[3])     # c
print(name[-1])    # e — последний символ
print(len(name))   # 7 — длина строки
```

Обращение к несуществующему индексу вызывает ошибку `IndexError`.

## Срезы

Срез вырезает часть строки: `строка[начало:конец]`. Символ с индексом «конец»
в результат **не входит** — так же, как в `range()`.

```python
ip = "192.168.10.25"

print(ip[0:3])     # 192
print(ip[:3])      # 192 — начало можно опустить
print(ip[4:7])     # 168
print(ip[-2:])     # 25 — два последних символа
print(ip[::-1])    # 52.01.861.291 — строка задом наперёд
```

Третье число в срезе — шаг. `[::-1]` означает «всю строку с шагом минус один».

## Строки нельзя изменять

```python
name = "sw-core"
name[0] = "S"
```

```text
TypeError: 'str' object does not support item assignment
```

Строка — **неизменяемый** тип. Любая операция создаёт новую строку,
а старая остаётся прежней. Чтобы «изменить» строку, результат записывают
в переменную заново:

```python
name = "sw-core"
name = name.upper()
print(name)        # SW-CORE
```

## Методы строк

Метод — это функция, которая «принадлежит» значению. Вызывается через точку.

```python
line = "  GigabitEthernet0/1 is UP  "

print(line.strip())               # убрать пробелы по краям
print(line.lower())               # всё в нижний регистр
print(line.upper())               # всё в верхний регистр
print(line.replace("UP", "DOWN")) # заменить подстроку
print(line.strip().startswith("Gigabit"))   # True — начинается ли с...
print(line.strip().endswith("UP"))          # True — заканчивается ли на...
print(line.count("t"))            # сколько раз встречается «t»
print(line.find("is"))            # позиция первого вхождения или -1
```

Методы можно вызывать цепочкой: `line.strip().lower()` сначала обрежет пробелы,
потом переведёт результат в нижний регистр.

Проверки содержимого:

```python
print("24".isdigit())     # True — только цифры
print("2a".isdigit())     # False
print("abc".isalpha())    # True — только буквы
```

`isdigit()` пригодится, чтобы проверить ввод до вызова `int()`.

## Оператор in

Проверяет, есть ли подстрока в строке:

```python
log = "Interface Gi0/1 changed state to down"

if "down" in log:
    print("Обнаружено падение интерфейса")

print("up" not in log)    # True
```

## split() — разбить строку на части

Один из самых полезных методов. Возвращает список частей.

```python
ip = "192.168.10.25"
octets = ip.split(".")
print(octets)          # ['192', '168', '10', '25']
print(octets[0])       # 192

line = "Gi0/1   up   up   uplink"
parts = line.split()   # без аргумента — делит по любым пробелам
print(parts)           # ['Gi0/1', 'up', 'up', 'uplink']
```

Части остаются строками. Чтобы работать с ними как с числами, нужен `int()`.

## join() — собрать строку из частей

Обратная операция. Вызывается у строки-разделителя:

```python
octets = ["192", "168", "10", "25"]
print(".".join(octets))      # 192.168.10.25
print(" -> ".join(["A", "B", "C"]))   # A -> B -> C
```

## Многострочные строки и спецсимволы

```python
config = """interface Gi0/1
 description uplink
 no shutdown"""
print(config)

print("Строка 1\nСтрока 2")    # \n — перевод строки
print("Имя:\tsw-core")         # \t — табуляция
```

Тройные кавычки позволяют писать текст в несколько строк. Метод
`splitlines()` разбивает такой текст на отдельные строки.

## Пример: разбор строки лога

```python
line = "2026-01-15 14:32:07 sw-core-1 ERROR Port Gi0/5 is down"

parts = line.split()
date = parts[0]
time = parts[1]
host = parts[2]
level = parts[3]
message = " ".join(parts[4:])    # всё остальное снова склеиваем

print(f"[{level}] {host}: {message}")
```
